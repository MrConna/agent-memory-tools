# Maintain Project Knowledge

1. Search `wiki/`, `memory/wiki/`, and existing learnings before creating a page.
2. Verify claims against current source files or tracked documents.
3. Update an existing concept/entity when possible; avoid synonyms as duplicate pages.
4. Keep one topic per page and link related pages.
5. Run `./bin/wiki sync` and resolve or explicitly retain stale markers.
6. Do not promote task progress, transient observations, or unverified inferences.

Use `wiki/concepts/` for terminology and mental models, `wiki/entities/` for systems and components, and `memory/rules/` for imperative project rules.
