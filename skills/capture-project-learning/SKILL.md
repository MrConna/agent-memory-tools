# Capture Project Learning

1. Search first with `./bin/memory search "<keywords>"`.
2. Record one durable pattern, not a progress update or raw transcript.
3. Assign confidence from evidence: 7 for verified once, 8 for repeated evidence, 9+ only for stable workflows.
4. Run lifecycle end with the learning, decisions, remaining work, and failed approaches.
5. Add tag `skill` only when the lesson is an executable repeatable workflow.

Never store secrets, credentials, private blocks, unsupported guesses, or rules already stated in project instructions.
